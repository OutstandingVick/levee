# Security policy

Levee is unaudited hackathon software. Do not deploy it with production funds.

Report vulnerabilities privately to the repository owner rather than opening a
public issue. Include affected contracts, reproduction steps, impact, and a
minimal proof of concept. Never test against contracts holding third-party funds.

Before mainnet use, obtain independent audits, use a multisig owner, bound oracle
staleness, verify every deployment address, cap deposits, and complete a staged
testnet and limited-capital rollout.
